## 📖 Descripción

**Este es un proyecto web interactivo, diseñada para la organización y gestión de actividades cotidianas. Permite a los usuarios registrar y visualizar tareas categorizadas por tipo (Estudio, Trabajo, Hogar) y prioridad (Baja, Media, Alta), estableciendo fechas límite y cambiando su estado de progreso (Por Hacer, En Progreso, Finalizado).**

---

## ✨ Características

## 📦 Instalación

1. Clonar el repositorio

```bash
git clone https://github.com/SneyderRodriguez/Planificador-Tareas.github.io.git
```

2. Ejecutar

```bash
node index.html
```

---

## 🚀 Uso

```
1. Ingresa Nombre de la Tarea.
2. Seleccion la Categoria y la Prioridad de la tarea.
3. Añade una descripción a la tarea.
4. Selecciona las fechas de inicio y fin.
5. Da clic en el botón crear
```
